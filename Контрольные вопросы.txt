1. **Что такое переменная:** Переменная в Python — это поименованная ссылка на область в памяти компьютера, где хранится значение (данные).
2. **Основные типы данных:**
* `int` — целые числа (`10`, `-5`)
* `float` — числа с плавающей точкой (`3.14`, `-0.5`)
* `str` — строки / текст (`"Привет"`)
* `bool` — логический тип (`True` или `False`)
* `list` — списки (`[1, 2, 3]`)

3. **Отличие `int` от `float`:** `int` хранит целые числа без дробной части, а `float` хранит вещественные (дробные) числа.
4. **Работа функции `input()`:** Приостанавливает выполнение программы, считывает введенный пользователем текст с клавиатуры до нажатия Enter и возвращает его.
5. **Преобразование результата `input()`:** Функция `input()` *всегда* возвращает данные в виде строки (`str`). Если введенное значение нужно использовать в математических вычислениях, его необходимо явно привезти к числовому типу.
6. **Назначение `int()` и `float()`:**
* `int()` — преобразует значение в целое число.
* `float()` — преобразует значение в число с плавающей точкой.


7. **Отличие `/` от `//`:**
* `/` — обычное деление, всегда возвращает `float` (например, `7 / 2` даст `3.5`).
* `//` — деление нацело, отбрасывает дробную часть и возвращает целую часть от деления (например, `7 // 2` даст `3`).


8. **Оператор `%`:** Вычисляет остаток от деления двух чисел (например, `7 % 2` даст `1`).
9. **Оператор `**`:** Используется для возведения числа в степень (например, `2 ** 3` даст `8`).
10. **Определение типа через `type()`:** Передайте переменную или значение в функцию в качестве аргумента: `type(x)`. Она вернет класс типа (например, `<class 'int'>`).
11. **Преобразование типов:** Это процесс изменения типа данных значения из одного в другой (бывает неявным, когда Python делает это автоматически, и явным, когда используются функции вроде `int()`, `str()`).
12. **Результат `int("Python")`:** Возникнет ошибка `ValueError`, так как строка `"Python"` не состоит из цифр и не может быть интерпретирована как целое число.
13. **Получение последней цифры числа:** Использовать остаток от деления на 10: `number % 10`.
14. **Удаление последней цифры числа:** Использовать целочисленное деление на 10: `number // 10`.
15. **Важность выбора типа данных:** Определение типа влияет на выделяемую память, на доступные над переменной операции и предотвращает логические или синтаксические ошибки при работе программы.
